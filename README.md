# Telltale Vercel backend

This Vercel-specific package has a root `index.py` FastAPI entrypoint plus the API, ML inference source and bundled trained models. For the required large-function project setting, root requirements, environment variables and deployment steps, follow `VERCEL_BACKEND_DEPLOY.md`.

This is a public demo configuration. The fixed demo token is public and must not protect sensitive or private data. Vercel function storage is temporary; persistent state and long-lived simulator tasks are not guaranteed.
